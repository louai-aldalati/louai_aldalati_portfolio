من أنا؟

طالب هندسة برمجيات أمتلك خبرة عملية في تطوير تطبيقات الويب (Django) وبناء أنظمة الذكاء الاصطناعي. أعمل على ابتكار حلول متكاملة تدمج تقنيات الواجهات الخلفية (Backend) مع النماذج اللغوية (LLMs) والرؤية الحاسوبية. أجيد ثلاث لغات بطلاقة، وأتميز بالتفكير التحليلي والقدرة على العمل ضمن بيئات متنوعة لحل مشكلات برمجية معقدة.

المشاريع التقنية

  • مساعد ذكي مخصص للشركات (AI Hotel Chatbot)
    التقنيات: Llama 3 (8B Instruct), RAG, Fine-Tuning, NLP
    • تطوير مساعد ذكي متقدم يعتمد على النموذج اللغوي مفتوح المصدر Llama 3 لتقديم ردود دقيقة ومؤتمتة.
    • تطبيق تقنيات التوليد المعزز بالاسترجاع (RAG) والضبط الدقيق (Fine-Tuning) لتخصيص إجابات النموذج بشكل كامل بناءً على قواعد وبيانات وسياسات فندق محدد، مما رفع من كفاءة خدمة العملاء.
    مشاهدة على GitHub
  • نظام التعرف على تعابير الوجه في الوقت الفعلي (Real-Time Emotion Recognition)
    التقنيات: Computer Vision, MobileNetV2, Transfer Learning, Python
    • بناء نظام رؤية حاسوبية محلي يحلل البث المباشر لكاميرا الويب لتصنيف 8 مشاعر إنسانية مختلفة (مثل السعادة، الحزن، الغضب) بدقة عالية.
    • استخدام تقنية نقل التعلم (Transfer Learning) عبر الاعتماد على معمارية النموذج المسبق التدريب MobileNetV2، وإعادة تدريب الطبقات النهائية (Fine-tuning) لتسريع الأداء وتقليل استهلاك الموارد.
    مشاهدة على GitHub
  • نظام تصفية المرشحين الذكي (Candidate Filter)
    التقنيات: Python, Django, spaCy (NLP), Tesseract OCR, PostgreSQL, Docker, Railway PaaS
    • تطوير منصة موارد بشرية سحابية تعتمد على تقنيات معالجة اللغات الطبيعية (NLP) والتعرف البصري (OCR) لأتمتة استخراج بيانات السير الذاتية وتوليد "درجة توافق" (Match Score) موضوعية مع متطلبات الوظيفة.
    • بناء الواجهة الخلفية باستخدام إطار عمل Django وقاعدة بيانات PostgreSQL، ونشر النظام عبر حاويات Docker على منصة Railway لضمان الأمان وقابلية التوسع.
    مشاهدة على GitHub
  • نظام ذكي لتخصيص الموارد (Smart Resource Allocation)
    التقنيات: Deep Reinforcement Learning (DQN), Python, PyTorch, Gymnasium, Algorithm Design
    • تطوير بيئة سحابية محاكية لحل مسألة حقيبة الظهر ثنائية الأبعاد (2D Knapsack) ديناميكياً، بهدف تحسين تخصيص موارد المعالج (CPU) والذاكرة (RAM) للمهام الواردة.
    • تدريب وكيل ذكاء اصطناعي يعتمد على شبكات Q العميقة (DQN) مع تحسين المعاملات الفائقة (Hyperparameters)، مما تفوق على الخوارزميات التقليدية (Greedy) وحقق 90.3% من كفاءة الحل الأمثل النظري (Dynamic Programming).
    مشاهدة على GitHub
  • نظام التنبؤ بالطقس (Weather Forecasting ML API)
    التقنيات: Machine Learning, XGBoost, Time-Series Analysis, Django, Django REST Framework
    • تصميم وتدريب نموذج تعلم آلة باستخدام خوارزمية XGBoost لتحليل البيانات الزمنية (درجة الحرارة، الرطوبة، اتجاه الرياح) والتنبؤ بالقيم المستقبلية.
    • تطوير الواجهة الخلفية للنظام باستخدام إطار عمل Django، وتقديم نموذج الذكاء الاصطناعي كخدمة برمجية متكاملة عبر واجهة برمجة تطبيقات (Django REST API) لسهولة ربطه مع تطبيقات الويب أو الموبايل.
    مشاهدة على GitHub
  • تطبيق Pawly لرعاية الحيوانات الأليفة (Pet Care Marketplace)
    التقنيات: Flutter, Dart, Firebase (Auth, Firestore, FCM), Google Maps API, NoSQL
    • تطوير تطبيق موبايل شامل لسوق خدمات رعاية الحيوانات الأليفة، يربط أصحاب الحيوانات بمقدمي الخدمات من خلال معمارية مرنة وديناميكية تدعم ثلاثة أدوار مختلفة (صاحب حيوان، مقدم خدمة، أو دور هجين يجمع بينهما) في تطبيق واحد.
    • هندسة الواجهة الخلفية (Backend) لتكون لحظية (Real-time) باستخدام Firebase Firestore، وتضمين ميزات متقدمة تشمل خرائط جوجل (Google Maps API) وتحديد المواقع (Geocoding)، بالإضافة إلى نظام الإشعارات الفورية (FCM).

    • بناء نظام متكامل يشمل المصادقة، الاختبارات التفاعلية، لوحات التقارير التحليلية، وإدارة التطوير باستخدام Agile/Scrum وGit.
